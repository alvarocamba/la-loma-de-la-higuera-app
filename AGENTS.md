# Proyecto La Loma

Lee `CODEX_HANDOFF.md` antes de modificar el proyecto. Continúa el rediseño y termina la integración funcional antes de hacer commit o desplegar.

Reglas del proyecto:

- La interfaz y todos los textos visibles deben estar en español.
- Diseño mobile-first, accesible y usable por personas no técnicas.
- Los importes se guardan siempre como céntimos enteros.
- El reparto predeterminado es igual entre las familias seleccionadas. Se puede ofrecer reparto proporcional por personas como alternativa.
- Conserva las siete familias iniciales y sus integrantes.
- No añadas servicios de Firebase que requieran el plan Blaze. El proyecto debe funcionar en Spark con Hosting, Firestore y Authentication anónima.
- No incluyas claves privadas, cuentas de servicio ni tokens. La configuración web de Firebase puede ser pública.
- Quien posea el enlace secreto del viaje puede leer y editar. Explica esta limitación en la pantalla de compartir.
- Antes del commit, ejecuta las pruebas de cálculo y verifica manualmente el flujo completo en escritorio y móvil.
